# dndrun

Браузерный draft-рогалик: собери обречённый отряд из пяти авантюристов и пяти заклинаний, затем проведи его по **Великому Походу** — сто этапов до Короны.

Вдохновлён механикой draft/симуляции [322-0](https://322-0.app), перенесённой в фэнтези-тон и лексику в духе SRD 5.1.

**Стек:** Vite · React 19 · TypeScript · CSS без UI-библиотек.

**Играть онлайн:** [https://numbers2k.github.io/dndrun/](https://numbers2k.github.io/dndrun/)

## Карта экранов

Один документ (`RunPage`) после старта забега: три кадра в потоке страницы.

| Кадр | Когда | Содержание |
|------|--------|------------|
| **Меню** | `screen === 'menu'` | Три слота кампаний, создание/хаб сейва |
| **Драфт** | `#run-draft` | Пентагон отряда + набор пака (5+5 карт) |
| **Поход** | `#run-campaign` | Горизонтальная лента 100 этапов, апгрейды после босса |
| **Итоги** | `#run-results` | Отряд / сила / карьера; монтируется после провала или короны |

Шапка (`SiteHeader`) и подвал (`SiteFooter`) общие. Первый запуск открывает модалку «Как играть» (`dndrun-howto-seen` в `localStorage`).

### Тайминги похода (актуальное состояние)

| Константа | Значение | Где |
|-----------|----------|-----|
| Вертикальный скролл к кадру | ~500 ms (ease-out) | `RunPage` |
| Пауза перед rewind / стартом | **1000 ms** | `FRAME_SETTLE_MS` |
| Откат ленты к этапу 1 | ~3200 ms (ease-in) | `REWIND_MS` |
| Один этап анимации | **1750 ms** | `STAGE_MS` |
| Скролл карточки этапа | ~420 ms | `TRACK_SCROLL_MS` |
| Резюме босса | 1000 ms | `BOSS_SUMMARY_MS` |
| Удержание fail / crown перед итогами | 3000 ms | `FAIL_HOLD_MS` |

Есть кнопка **Пропуск** — обрывает анимацию этапов.

## Цикл игры

### 1. Кампания (сейв)

- 3 слота в `localStorage` (`dndrun-saves-v1`, активный — `dndrun-active-save`).
- При создании: имя отряда + сложность (**Сложно** 0 / **Средне** 3 / **Отдых** 5 перебросов набора) — навсегда для слота.
- Карьера копится в сейве: лучший этап, короны, открытия рас/классов/подклассов/тиров/школ, история забегов (до 20).

### 2. Драфт

1. Выдаётся **набор** (имя роты + «глава» пака): **5 авантюристов** и **5 заклинаний**.
2. За ход берёшь **только одно**: героя *или* заклинание → набор обновляется.
3. Цель: **5 героев + 5 спеллов**.
4. Перебросы набора ограничены сложностью.
5. После 5+5: **Начать Великий Поход** или **Бросить отряд** (новый seed, тот же сейв).
6. Спеллы рассаживаются автоматически; после драфта можно перетаскивать между героями.

**Роли:** Танк / Удар / Контроль / Поддержка / Разведка. Любой класс может получить любую роль, но слабая **посадка** режет силу.

**Сила отряда (оси):** База · Посадка · Статы · Спеллы · Связки · Роли → итоговое **overall** (центр радара).

### 3. Великий Поход

- 100 этапов = **10 глав × 10** (9 маршрутов + босс главы).
- Симуляция (`planCampaign`): сила отряда vs difficulty этапа + шум; на этапе 2–3 схватки.
- После **босса** (если жив): краткое резюме → **3 усиления спеллов** (или пропуск) → продолжение.
- Провал или прохождение 100 → удержание кадра → кадр **итогов**.
- Новый забег с прогрессом карьеры: лента сначала на `bestStage`, затем rewind к этапу 1 («призраки» пройденного).

### 4. Итоги

- Слева: отряд, строка характеристик, кнопки «Новый забег» / «В меню».
- Справа: карьера (всего / глубже 30 / последний) и до **9** последних забегов.
- Колонки как на драфте: `1.15fr` / `1fr`. Кадр по высоте контента — подвал сразу под колонками.

## Путь из 100 этапов

Сложность этапа растёт примерно так: `62 + (n−1)×0.42` (+3 для босса).

### Главы (боссы)

| Гл. | Босс (имя главы) | Blurb |
|-----|------------------|-------|
| 1 | Пепельная дорога | Первые засады и пыль тракта |
| 2 | Соляные топи | Топи, соль и слепые твари |
| 3 | Костяной перевал | Узкие тропы под обстрелом |
| 4 | Лунные руины | Проклятые алтари под луной |
| 5 | Склеп Эха | Нежить и ловушки гробниц |
| 6 | Багровый мост | Мост над пропастью огня |
| 7 | Берег Бездны | Разломы и шёпот пустоты |
| 8 | Чёрные врата | Культисты у порога трона |
| 9 | Чертог Короны | Элитная стража короны |
| 10 | Трон Короны | Финальный владыка пути |

### Маршруты внутри главы (индексы 1–9)

Засада у обочины · Туманная гряда · Соляной штрек · Костяной спуск · Лунный двор · Эхо коридора · Багровый сход · Разлом берега · Чёрный проход · *(10-й слот — босс)*.

На карточках похода: **имя** → атмосфера места (`stagePlaceLore`) → судьба (`stageFateLore`: ждёт / корона пала / путь оборвался…) — без сухих «угроза vs OVR» и без подписей «Маршрут/Босс».

Стартовый пул: расы human/elf/dwarf/halfling; классы fighter/wizard/cleric/rogue/ranger; тир спеллов ≤ 2; школы Воплощение, Ограждение, Очарование, Прорицание, Вызов.

| 30 | Гном, Колдун, школа Иллюзия |
| 40 | Друид, Чемпион, тир 4 |
| 50 | Драконорожденный, Варвар, Жизнь |
| 60 | Монах, Чародей, тир 5, Преобразование |
| 70 | Полуорк, Вызыватель, Вор |

| 100 | тир 9, Дикая магия (+ полный пул рас/классов) |
