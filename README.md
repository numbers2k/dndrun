# dndrun · Путь отряда

Мрачный карточный рогалик о трёх героях, общей колоде и дороге за последним костром. Версия 0.4 добавляет бесконечное продолжение, связки карт, счёт и локальную таблицу рекордов.

**[Играть в браузере — на телефоне или компьютере](https://numbers2k.github.io/dndrun/)**

## Играть локально

Требуется Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173/dndrun/. Сохранения привязаны к браузеру и адресу: `localhost` и `127.0.0.1` имеют разные данные.

## Бой и сборка

- Выберите стартовый отряд: защита и лечение; метки и яд; энергия и массовые заклинания.
- В бою общая колода и 3 энергии на ход. Выберите карту, затем цель. Массовые карты применяются сразу. Враги заранее показывают следующий урон и цель; при выборе атаки видна точная потеря здоровья противника.
- Чередуйте владельцев карт: серия из 3 карт даёт добор, из 5 — энергию. Каждая награда выдаётся один раз за ход. Повтор карты того же героя начинает серию заново; новый ход сбрасывает её.
- Защита обновляется в начале хода. Яд срабатывает перед атаками врагов и убывает на 1. Уязвимость усиливает атаки на 50%. После седьмого хода враги усиливают атаки на 2 за ход.
- Здоровье сохраняется между боями. Карты павшего героя недоступны. Привал позволяет отдохнуть, улучшить карту или поднять героя; улучшения можно повторять до уровня +20. Босс восстанавливает отряд.
- Победы дают карты, монеты и реликвии. Карту можно пропустить; короткая колода помогает находить сочетания. Торговец продаёт карты и реликвии и убирает ненужные карты. После первых двух боссов можно заменить героя вместе с его картами.

В игре 6 героев, 36 карт, 12 реликвий, 3 области, боссы, элитные бои, события, привалы и торговцы. Обучение встроено в первый бой, подробные правила доступны через «Как играть». Звуки включаются отдельно.

## После дракона

Основной путь занимает 15 остановок, с боссом на каждой пятой. После последней награды можно вернуться с результатом или продолжить в бездну. Колода, её улучшения, отряд, реликвии и очки сохраняются.

Каждый следующий круг предлагает один из четырёх складывающихся даров: урон атак, усиление яда, защита отряда или стартовая энергия и добор. Отряд получает не менее 75% здоровья и 40 монет. Случайное знамение меняет правила следующего круга: броня врагов, меньше стартовых карт, дополнительные противники или усиленные атаки.

За каждые следующие 15 остановок снова доступен выбор продолжения. Фиксированного предела остановок нет. Генерируются новые развилки и составы встреч; три области и архетипы боссов повторяются с усилением. Здоровье врагов растёт в 1,22 раза за круг, сила атак — на 2. Постоянных усилений между отдельными забегами нет.

## Очки и рекорды

За бой: стычка 100, элита 250, босс 600. Бонус темпа — `max(0, 6 − номер хода) × 25`, без потери здоровья — 100, лучшая связка — 20 за карту, максимум 200 за бой. Мирная остановка даёт 25. Сумма умножается на `1 + 0,4 × число кругов бездны`, в опасном режиме дополнительно на 1,5, затем округляется. Урон и лечение сами по себе очков не дают.

Результат записывается после возвращения или гибели. Таблица хранит до 100 лучших результатов и показывает первые 20 выбранного режима: обычного, опасного или дневного. Введите имя перед походом; на одном устройстве друзья могут играть под разными именами. Дневной путь использует фиксированный отряд и seed даты в локальном часовом поясе; для одного имени и seed сохраняется лучший результат.

Таблица **локальная**: данные остаются в этом браузере, общей сетевой таблицы и сервера нет. После первой победы открывается опасный поход: +4 к атакам врагов и +25% здоровья боссам. Первый учебный бой остаётся одинаковым.

## Сохранения

Поход и профиль сохраняются автоматически. Журнал хранит найденные карты, реликвии и 20 последних результатов. Сохранения v0.3 подхватываются, но старые забеги не попадают в таблицу новых правил. Ключи `dndrun-expedition-v3` и `dndrun-guild-v3` сохранены для совместимости. Сохранения v0.2 не используются и не удаляются.

## Разработка и проверки

```sh
npm run test:unit      # 41 проверка правил, рекордов и сохранений
npm run smoke:balance  # 700 забегов: три отряда, две стратегии, опасный режим
npm run smoke:endless  # 150 забегов с продолжением до четырёх кругов
npm test              # все три проверки
npm run lint
npm run build
npm run preview
npm run format
```

CI выполняет lint, тесты и сборку перед публикацией на GitHub Pages.

- `src/expedition/engine.ts` — детерминированный движок и сохранения.
- `src/expedition/data.ts` — герои, карты, реликвии, области и события.
- `src/expedition/endless.ts` — дары и знамения бездны.
- `src/expedition/Leaderboard.tsx` — локальные рекорды.
- `src/expedition/Art.tsx` — SVG-пейзажи, персонажи и иконки.
- `src/App.tsx` — интерфейс и управление походом.
- `tests/` — проверки правил, симуляционный игрок и изолированные UI-сценарии.

При запущенном Vite `http://localhost:5173/dndrun/tests/ui.html?scenario=checkpoint` открывает контрольную точку после дракона, `?scenario=board` — завершённый поход с тестовыми рекордами. Эти сценарии **заменяют тестовые сохранения на localhost**, поэтому для обычной игры используйте `127.0.0.1`. Они не входят в production-сборку.

Старый движок и временные материалы удалены из проекта. Шрифты загружаются из Google Fonts, при отсутствии сети используются системные. Игровой процесс не требует аккаунта, сервера или внешних игровых API. Имена, тексты и SVG-иллюстрации созданы для «Пути отряда».
