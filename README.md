# dndrun · Путь отряда

Мрачный карточный рогалик: **три героя, одна колода, решает порядок карт**. Кампания на 15 остановок продолжается в процедурной бездне с сохранением сборки.

**Версия 0.6.** Серверной таблицы рекордов нет: результаты и настройки хранятся в этом браузере.

**[Играть в браузере](https://numbers2k.github.io/dndrun/)**

## Запуск

Node.js 22.12+ или 24:

```sh
npm ci
npm run dev
```

Для обычной локальной игры рекомендуем http://127.0.0.1:5173/dndrun/. Сохранения привязаны к браузеру и адресу: localhost и 127.0.0.1 используют разные данные.

## Что изменилось в 0.6

- Сначала условия похода, затем стандартная тройка с редактором. На новом профиле открыты Страж, Следопыт и Целитель; знакомство или предложение рекрута открывает остальных для следующих стартов без усиления характеристик.
- Обычный поход и три открываемых испытания: Без целителя, Короткая рука, Пепельный след. Полная коллекция даёт 84 уникальные тройки и 308 сочетаний тройки с условиями. Дневной состав фиксирован.
- Общий стартовый фонарь. Дополнительный добор ограничен четырьмя картами за ход; Парирование Дуэлянта теперь добирает карту. Опасный режим даёт +4 силы вместо +5.
- Плетельщик завес и Бродячий бронник; четыре новые группы встреч. Две новые сделки: улучшение выбранной карты за постоянный Пепел и подготовка следующих двух боёв.
- Результат действия показывает передачу между героями, урон, защиту и подготовку. Разные звуки эффектов, выключенный по умолчанию звук, крупный текст и исправленная навигация телефона.
- Рекорды разделяются по версии правил, режиму, условиям и начальному составу. Вызов сохраняет начальную тройку даже после замен в пути. Старые ссылки 0.5 нельзя честно воспроизвести в новых правилах, поэтому они отклоняются.
- Таблица сохраняет до 10 лучших результатов каждой версии, режима, испытания и тройки. Настройки звука и крупного текста переживают перезагрузку.
- Пепел нельзя выбрать для улучшения. Завершение боя не приписывает наградное лечение сыгранной карте; эффекты уязвимости и ограниченного добора объясняются яснее.
- На телефоне боевой экран стал компактнее: верхняя навигация, противники и отряд занимают меньше места. Учитывается системное уменьшение движения.

Отчёт, пересмотренный план и ограничения: [docs/expedition-start-audit.md](docs/expedition-start-audit.md).

## История изменений 0.5

- 9 героев, 6 стартовых отрядов, 54 игровые карты, 21 реликвия. Новые герои: алхимик, дуэлянт и провидец. Реликвии позволяют удержать карту, превратить остаток защиты в удар, взорвать яд или усилить дорогие атаки ценой меньшей руки.
- 12 обычных типов врагов и 18 составов встреч по трём областям. Последние три встречи не повторяются. Есть защита союзников, усиление, ритуалы, проклятия, реакция на смерти и похищение здоровья.
- 7 боссов с четырьмя семействами правил: эхо, печать, призыв, охота. Правило объявлено заранее. В кампании третий босс — дракон, затем состав меняется.
- 10 дорожных событий; последние четыре не повторяются. Кузнец улучшает выбранную карту, коллекционер убирает выбранную, лекарь возвращает героя, встреченный спутник предлагает замену.
- После элиты и босса выбирайте реликвию из трёх, затем карту. Пока есть доступные реликвии, выбор обязателен; при исчерпании коллекции можно идти дальше.
- Необязательное испытание раскрывается на маршруте. Врагам +2 к атаке. Победа до третьего хода, связка из четырёх карт или победа без ран дают +15 монет и +80 очков с множителем. Провал сохраняет обычную награду. Учебный бой без испытания.
- Итог сборки показывает лучший урон за эффект, связку, прерванные ритуалы и испытания. Кнопка копирует результат и ссылку другу на одинаковый старт: seed, отряд, режим и правила 0.5. Ссылка не начинает поход автоматически. Разные решения могут привести к разным дальнейшим событиям.
- Рекорды 0.4 доступны в отдельном архиве.

Обоснование изменений и исследование 12 успешных инди-релизов: **[docs/indie-research.md](docs/indie-research.md)**. Три цикла разработки, конкурентный анализ и результаты баланса: [docs/improvement-cycles.md](docs/improvement-cycles.md). Проверенные данные Steam: [docs/indie-snapshot.json](docs/indie-snapshot.json).

Затем выполнены **[пять циклов проверки первого опыта](docs/player-experience-audit.md)**: два полных UI-похода, целевые сценарии, оценка интерфейса и баланса, следующий план. Числа предыдущего отчёта относятся к этапу до этой проверки.

- Подсказки показывают следующий шаг серии, доступные карты и сгорающий остаток энергии. Полные правила серии раскрываются отдельно.
- Прогноз конца хода учитывает смертельный яд, эффекты смерти, перенаправление атак и защиту; выбранная поддержка показывает настоящий результат.
- Реликвия выбирается перед картами. При наличии совместимой реликвии хотя бы одна попадает в предложение. Замена спутника показывает потерянные карты/улучшения; привал и кузнец показывают эффект следующего уровня до выбора.
- Припасы лечат раненого с наименьшей долей HP. Боевые альтернативы одного маршрута имеют разные составы.
- Во второй/третьей областях врагам +1/+2 силы, боссам дополнительно +10%/+20% HP. Обучение и первая область сохраняют прежние числа. Дракон обычной кампании: 252 HP, базовое дыхание 14.
- На узком экране герои расположены широкими строками, после применения к цели игра возвращает к руке. Экран поражения показывает последние события боя.

## Правила

Общая колода и 3 энергии на ход. Выберите карту, затем цель; массовые и личные карты срабатывают сразу. Намерения врагов видны до завершения хода, выбор атаки показывает точную потерю здоровья цели.

Чередуйте владельцев: связка из 3 карт даёт добор и урон ×1,25, из 5 — энергию и ×1,5, из 7 — ×1,75, из 9 — ×2. Камертон добавляет +0,25 с третьей карты ценой меньшего добора. Проводник яда и Клятва щита передают подготовленный бонус атаке другого героя. Один экземпляр карты можно сыграть раз за ход; копии работают отдельно. Бонусы срабатывают по разу за ход. Повтор владельца начинает серию заново, новый ход сбрасывает её.

Защита обновляется в начале хода. Яд наносит урон перед атаками врагов, обходит защиту и убывает на 1. Уязвимость усиливает атаки на 50%. Ритуал прерывают 10 единиц урона по здоровью за ход; поглощённый защитой урон не считается. Пепел нельзя сыграть; он исчезает после одного хода в руке, очищающие карты убирают весь Пепел из боя. После седьмого хода враги усиливаются на 2 урона каждый следующий ход.

Здоровье сохраняется. Карты павшего героя недоступны; привал позволяет лечить, улучшать пригодную карту до +20 или поднять павшего. После босса павшие возвращаются с 40% здоровья, живые получают до 12 здоровья. Карту награды можно пропустить. Торговец продаёт карты и реликвии и удаляет карты, но не уменьшает колоду ниже шести.

## Бездна

После каждой пятнадцатой остановки можно вернуться с результатом либо продолжить. Сборка и очки сохраняются. Выбирается один из четырёх складывающихся даров: атака, яд, защита, стартовые энергия/добор. Здоровье восстанавливается минимум до 75%, выдаются 40 монет.

Каждый круг приносит знамение: броню, меньшую руку, дополнительного врага или усиление атак. Здоровье врагов умножается на 1,3 в степени числа кругов бездны, сила атак увеличивается на 3 за круг. Встречи процедурно выбираются из авторского контента; области и семейства правил повторяются. Фиксированного предела остановок нет. Постоянных усилений между отдельными забегами нет.

Опасный поход открывается после первой победы: +4 к атакам и +40% здоровья боссам. Учебный бой одинаковый.

## Очки, вызовы и сохранения

За бой: стычка 100, элита 250, босс 600. Темп: max(0, 6 − номер хода) × 25; без ран — 100; лучшая связка — 20 за карту, максимум 200. Завершающий удар карты в серии от 3 даёт избыток силы после брони над здоровьем цели, максимум 150; за бой учитывается только лучший. Яд, взрывы и призванные помощники этот бонус не дают. Мирная остановка даёт 25. Множитель: 1 + 0,4 × число кругов бездны, в опасном режиме дополнительно ×1,5. Испытание отдельно даёт 80 с тем же множителем. Урон и лечение сами по себе очков не дают, призванные помощники не дают отдельной награды.

Результат записывается после гибели или возвращения. Локальная таблица хранит до 10 лучших результатов каждой категории и показывает до 20 сохранённых записей. В дневном походе отряд фиксирован; seed даты зависит от местного часового пояса. Ссылка фиксирует конкретный seed даже на следующий день. Для одного имени/старта/режима/версии сохраняется лучший результат.

**Лидерборд локальный, сервера и сетевой проверки очков нет.** Ссылка переносит стартовые условия, а не сохранение или запись в таблице. Локальные ссылки доступны только на соответствующем устройстве; отправлять друзьям приглашения новой версии имеет смысл после утверждённой публикации. Версия 0.4 не поддерживает приглашения 0.5.

Сохранения 0.3/0.4 подхватываются, рекорды не смешиваются. Старый бой можно закончить; дальнейшие встречи используют обновлённый контент. Ключи dndrun-expedition-v3 и dndrun-guild-v3 сохранены. Данные 0.2 не используются и не удаляются. Журнал хранит найденные карты, реликвии и 20 последних походов. Внешней игровой аналитики нет.

## Проверки

```sh
npm run test:unit       # правила, рекорды, настройки и сохранения
npm run test:variety    # разнообразие механик, наград и ссылок
npm run test:combo      # связки и таблица урона
npm run test:audit      # первый опыт, прогнозы и награды
npm run test:contracts  # условия похода и стартовый состав
npm run test:iteration  # новые враги, события и обратная связь
npm run smoke:contracts # баланс условий и стартовых составов
npm run smoke:players   # 960 походов двух эвристик и двух стилей маршрута
npm run smoke:rosters   # 840 походов: каждая из 84 троек
npm run smoke:deep      # 30 стресс-походов с целью 150 остановок
npm run smoke:balance   # 1300 забегов: шесть отрядов, две стратегии, опасный режим
npm run smoke:endless   # 300 забегов до четырёх кругов
npm test
npm run lint
npm run build
npm run preview
npm run format
```

Бот проверяет проходимость и инварианты, не удовольствие игрока. Его процент побед не равен человеческому. План плейтестов и ограничения исследования описаны в отчёте. CI выполняет lint, тесты и сборку перед GitHub Pages.

- src/expedition/engine.ts — движок, счёт и сохранения.
- data.ts, companions.ts, encounters.ts — герои, карты, роли и составы врагов.
- challenges.ts — испытания, приглашения и итог сборки.
- endless.ts, Leaderboard.tsx — бездна и рекорды.
- Art.tsx, ui.tsx, src/App.tsx — SVG-иллюстрации и интерфейс.
- tests/ — проверки правил, бот и изолированные UI-сценарии.

При запущенном Vite http://localhost:5173/dndrun/tests/ui.html?scenario=boss открывает тест печати; варианты combo, ritual, visitor, reward, route, checkpoint, board, first-visit, supplies, forecast, dragon-audit, upgrade проверяют остальные экраны. tests/mobile.html проверяет адаптивную раскладку в iframe 390 × 844. Они **заменяют тестовые данные localhost**, поэтому для обычной игры используйте 127.0.0.1. В production-сборку сценарии не входят.

Шрифты загружаются из Google Fonts; без сети используются системные. Для игры не нужны аккаунт, сервер или внешние игровые API. Исследовательские документы в docs сохранены намеренно.
