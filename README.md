# dndrun

Браузерный draft-рогалик: империя слишком долго пировала — спустилась **Порча Пира**. Собери обречённый отряд и проведи вылазку через сто испытаний к **Немой Колокольне**.

**Играть онлайн:** [https://numbers2k.github.io/dndrun/](https://numbers2k.github.io/dndrun/)

---

## Смысл игры

Ты — мастер вылазки гильдии. Набираешь пятерых авантюристов и пять заклинаний, складываешь их в силу отряда и ведёшь команду по краям, искажённым Порчей.

Откуда пришло проклятие — неизвестно. Цель одна: дойти до конца пути и сразить **Распорядителя Пира**, чтобы оборвать пир.

Вылазка — это **10 глав снизу вверх** (как уровни Dead Cells). На каждом ярусе 2–3 двери только вперёд; назад нельзя. Старт и финал фиксированы, середина каждый раз другая.

Сохранения лежат в браузере — до **трёх записей гильдии**. Прогресс открытий (расы, классы, края, тиры заклинаний) остаётся между вылазками; сам маршрут при новой вылазке начинается заново.

## Как играть

### 1. Запись гильдии

1. Открой игру и выбери свободный слот.
2. Задай имя отряда и сложность (перебросы и базовая угроза). Сложность потом не меняется.
3. Начни вылазку — или продолжи незавершённую, если она сохранилась.

### 2. Драфт

Справа появляются наборы карт:

- **Авантюристы** — роль, раса, класс, удар / ресурс / надёжность, личный рейтинг, редкость.
- **Заклинания** — уровень или «Фокус», школа, давление / контроль / поддержка.

Правила набора:

1. Кликни карту → подробности.
2. Подтверди выбор.
3. Из одного набора берёшь **только одно**: героя **или** заклинание.
4. Можно перебросить набор (число перебросов зависит от сложности).
5. Нужно набрать **5 героев** и **5 заклинаний**.

Когда пятёрки собраны:

- **Начать вылазку** — идти на путь;
- **Бросить отряд** — драфт заново в той же записи гильдии.

Редкость карт: **обычная · редкая · легендарная**. Легендарки редки — сильный ordinary часто сильнее тощего rare.

### 3. Сила отряда

| Ось | Смысл |
|-----|--------|
| **База** | Средний личный рейтинг героев |
| **Посадка** | Роли на классе и расе |
| **Статы** | Удар, ресурс, надёжность под роли |
| **Спеллы** | Пул и рассадка по героям |
| **Связки** | Сочетания героев |
| **Роли** | Покрытие пяти ролей |

Исход столкновений: **сила отряда ≥ угроза**. Без кубика «удачи» — решает состав и выбор пути.

На пентагоне можно перетаскивать заклинания между героями, когда отряд собран.

### 4. Вылазка

1. Лента из **100 этапов** (10 глав × 10).
2. Можно нажать **Пропуск**, чтобы ускорить анимацию.
3. После босса главы (кроме подхода к финалу):
   - выбор **края Порчи** (дверь на следующий ярус);
   - решение маршрута (**осторожно** / **напролом**);
   - **усиление заклинания** (уровень, владение или замена).
4. Провал или победа над Распорядителем открывают итоги.

Чем дальше идёшь, тем жёстче угроза. Безопасный край и осторожный маршрут помогают, но не делают путь бесплатным.

### 5. Журнал гильдии

В записи гильдии открой **Журнал** — там только то, что уже встречали:

- края по главам;
- расы, классы, подклассы;
- заклинания.

Незнакомое скрыто туманом. Журнал удобно листать по вкладкам.

## Подсказки

- Кликай карты — в попапе видны теги, школы и причуды героев.
- Сочетай роли и заклинания, а не только «самое редкое».
- Логотип **dndrun** в шапке возвращает в меню.
- **Как играть** в шапке — краткая справка внутри игры.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` · превью: `npm run preview`

Игра деплоится на GitHub Pages из ветки `main` (workflow в `.github/workflows`).
